PDF CERIA — VERSI GRATIS SIAP PUBLIK

CARA PUBLIKASI PALING MUDAH:
1. Buat akun GitHub gratis di github.com
2. Buat repository baru, misalnya: pdf-ceria
3. Upload SEMUA file dalam folder ini ke repository.
4. Masuk Settings > Pages.
5. Pada Build and deployment pilih:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6. Simpan.
7. Tunggu beberapa saat. GitHub akan memberikan alamat website Pages.

CATATAN:
- Jangan mengubah nama index.html.
- Aplikasi tidak membutuhkan database.
- PDF diproses di browser pengguna.
- Untuk PWA/install, website harus HTTPS. GitHub Pages menyediakan HTTPS.
- PDF.js saat ini dipanggil dari CDN. Jadi koneksi internet tetap diperlukan saat pertama kali membuka/menggunakan aplikasi.
